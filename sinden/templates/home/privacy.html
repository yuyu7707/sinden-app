プライバシーポリシー

祠で書く訴えや手紙は、とても私的なものです。 このページでは、Placaの祠（以下「祠」）が何を預かり、どこへ送り、誰が見られるのかを説明します。

祠について

祠は、スパルタキャンプの自主制作として作った作品です。運営は yuyu7707（個人）が行っています。 学習のための作品のため、大きな会社のサービスと同じ水準の守りや、長い期間の運営はお約束できません。

預かる情報

  • 登録の情報：呼び名、メールアドレス、パスワード。パスワードは元に戻せない形（ハッシュ）にして保存し、運営者も元のパスワードを見ることはできません。
  • 祠で書いたもの：訴え、女神の鏡、ことばの灯、残した記録、手紙。
  • 支払いの状況：入っているプラン、決済会社の顧客番号。カード番号は祠のサーバーを通らず、祠では預かりません。
  • 接続の情報：サーバーの記録（アクセスログ）に、接続元の IP アドレスと開いたページが残ります。ログインや登録を何度も試されたときに止めるため、IP アドレスごとの回数を一時的に数えます。

外のサービスへ送るもの

  • 女神の鏡・ことばの灯（Anthropic 社の Claude API）： 「ことばを確かめる」を押したときだけ、訴えの文を送ります。呼び名やメールアドレスは送りません。 Anthropic 社の商用規約では、API で送った内容をモデルの学習に使わないとされています。
  • 支払い（Stripe 社）： プランに申し込むとき、メールアドレスと金額を送ります。カードの情報は Stripe の画面に直接入力します。
  • 声で訴える（お使いのブラウザの音声認識）： 声を文字にするのは、祠ではなくブラウザの機能です。Chrome などでは、声がブラウザの提供元（Google 社など）のサーバーに送られて文字になります。 気になるときは、文字で書いてください。
  • 画面の表示： 書体（Google Fonts）とデザインの部品（jsDelivr）を外のサーバーから読み込むため、そのサーバーに接続元の IP アドレスが伝わります。祠で書いた内容は送りません。

見られる人

  • 訴え・残した記録・手紙は、ペアのふたりだけが見られます。
  • 女神の鏡、ことばの灯、届ける前の下書きは、書いた本人だけが見られます。相手には届けた言葉だけが届きます。
  • 運営者は、サーバーの管理のためにデータベースに触れることがあります。障害の対応など必要なときを除き、中身を読むことはしません。
  • 法律にもとづいて求められた場合を除き、預かった情報をほかの人や会社に渡しません。

消し方

  • 祠を出るとき、どちらかが「残さない」を選ぶと、その祠の訴えはすぐに消えます。
  • 退会すると、あなたのアカウントと、ふたりの祠・記録・手紙が消えます（相手の分も含みます）。 プランに入っているときは、先に解約してください。
  • 支払いの記録は、法律で決められた期間、Stripe 社に残ります。

問い合わせ

GitHub の Issues にお寄せください。 Issues は誰でも読める場所です。訴えの内容やメールアドレスなど、あなたや相手のことがわかる情報は書かないでください。
