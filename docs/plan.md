## 1. タイトルとキャッチコピー

- **タイトル**：Placaの祠（プラカのほこら）
  - 由来：古代ローマで、喧嘩したふたりが一緒に訪れた女神ヴィリプラカの祠。「Placa」は女神の名と、ラテン語の placare（鎮める・なだめる）から
- **キャッチコピー（決定）**：喧嘩を、終わりにしないための祠。
  - サブ：ひとりずつ話して、最後まで聴く。2000年前のローマの仲直りの知恵を、スマホに。
- **キャッチコピーの初期案（不採用）**
  - 「言い返せない5分間が、ふたりを落ち着かせる」
  - 「喧嘩したら、ふたりで祠へ」
  - 「ふたりで入って、ひとりずつ話す場所」

## 2. 想定ユーザーと課題

### 誰のために？
- 世の中の夫婦・恋人たち
- 特に**交際して間もない、関係が良いうちに**ふたりで登録しておき、こじれ始めたときや、関係は続けたいのにうまくいかないときに使ってほしい
- 別れる間際の「最後の最後」に使うものではなく、関係を続けたいふたりのためのもの（2026-11-20 に方針を改めた）

### どんな悩みを解決したいか？
困りごとは、次の3つに分けられる。

| 困りごと | 具体的な場面 |
|---|---|
| ① ヒートアップする | 言い合いが止まらない／黙ったら負けだと思って話し続ける／子どもの前でしてしまう |
| ② 言えない | 片方が黙り込む／うまく伝えられない／話しにくい内容がある |
| ③ くり返す | 同じ喧嘩を何度もしてしまう |

### 現在の代替手段の課題
- 対面の話し合い：割り込み合いになり、声の大きい方が勝つ
- LINE などのメッセージ：既読・即レスの応酬で、かえってヒートアップする
- カウンセリング：費用と予約のハードルが高く、「いざという時」に間に合わない
- 我慢する：言いたいことが言えないまま、関係が終わってしまう

### 前提にする考え方
- **非はどちらか一方ではなく、双方に言い分がある**
- 女神の名前の語源（「夫をなだめる」）は、アプリでも発表でも使わない

## 3. アプリのコンセプト

### 一言で
**「喧嘩したふたりが、スマホの中の祠で一人ずつ訴える場所」**

### 元になったエピソード
塩野七生『ローマ人の物語』第1巻より。古代ローマのパラティーノの丘には、夫婦喧嘩の守護神ヴィリプラカの小さな祠があった。

- 喧嘩がエスカレートしたら、ふたりで祠に出向く
- 祠には女神の像があるだけで、神官も誰もいない
- 掟は「**女神に訴えるのは一時に一人**」
- 一方が訴えている間、もう一方は黙って聴くしかない。すると、相手の言い分にも理があると気づく
- 訴えている本人も、静かな祠に響く自分の声を聴き、自分を俯瞰して落ち着いていく
- **何も肯定しない女神**の前で、**何も言い返さない相手**に、怒り続けるのは難しい
- これをくり返すうちに、ふたりは仲良く祠を後にする。ふたりが選んだのは「和解」

この祠は文献にただ1か所記録があるだけで、遺跡も写真も残っていない。
→ **「だから、スマホの中に祠を建て直した」**

### 差別化ポイント
1. **AIが裁かない・助言しない**：AIは審判にも相談相手にもならない。女神はただ静かにそこにいる
2. **掟をアプリが守らせる**：話す番の人だけが入力でき、相手は割り込めない
3. **相手の存在を感じられる**：女神の像の足元に、ふたりの灯りがともる。スマホに向かって話していても、相手が隣で聴いているとわかる
4. **関係が良いうちに備える**：こじれてからではなく、仲の良いうちに登録しておく「お守り」のようなアプリ

## 4. 機能のイメージ

### コア機能（3つ）

#### 機能1：ふたりで祠に入る（ペア登録と祠への誘い）
- 片方が登録して**招待コード**を発行し、もう片方が入力するとペアになる（関係が良いうちに行う）
- 喧嘩したら、片方が「**祠へ行こう**」と誘う
- **もう片方が「応じる」を押して初めて祠が開く**（ふたりで出向くこと自体が最初の歩み寄り）
- 祠に入ると掟が表示され、ふたりとも「掟に従う」を押して始まる

#### 機能2：一人ずつ訴える
- 話す番の人だけが入力できる。相手側の画面には「**いまは聴く番です**」とだけ表示され、入力欄は出ない
- 入力は**文字**と**音声**のどちらでもよい（音声はブラウザの音声認識で文字にする）
- 1回の訴えは**最大5分**。途中で自分から「訴え終える」を押してもよい
- 訴え終えると、本人の画面にだけ「**女神の鏡**」（AIによる言い換え）が表示される
  - 本人が自分の訴えを俯瞰するためのもので、**相手には見せない**
- 相手には、**本人が書いた（話した）生の言葉**がそのまま届く
- 番が交代し、これをくり返す
- 画面には女神の像と、その足元に**ふたりの灯り**がある。相手が画面を開いていれば相手の灯りがともる。話している人の画面には「〇〇さんが隣で聴いています」と出る

#### 機能3：和解の記録
- どちらかが「祠を出よう」と提案し、**ふたりとも押すと**「和解」の画面になる
- 最後に、記録を**残す／残さない**を選ぶ
  - ふたりとも「残す」を選んだときだけ記録される。どちらかが「残さない」なら、その回の訴えはすべて削除する
- 記録が残っていれば、ふたりで過去の喧嘩と和解を振り返れる（同じ喧嘩のくり返しに気づく）

### 有料プラン（ペアで1つ）

- 月額プランは2つ：**個人プラン（500円/月）** と **ふたりプラン（800円/月。個人2人分より200円お得）**。Stripe で支払う
- 個人プランは、本人だけの機能（鏡・声・学び・手紙を書く）は入った本人だけ、共有する機能（ローマの朝・記録）はふたりとも使える
- 女神の鏡は1人あたり月30回（3日に1回喧嘩しても足りる量）。使い切ったら **追加10回 100円**（1回払い・期限なし。プランの人だけ購入できる。無料の人にはプランを案内する）
- 買い切りプランは作らない（AI の費用がずっと続くため）
- 月額プランの解約・カードの変更は、Stripe のカスタマーポータルで行う
- 収支（最悪の場合）：個人 約+378円／ふたり 約+566円／追加10回 約+63円（鏡1回 約3.3円、手数料 約4.3%）

| | 無料 | 個人プラン 500円/月 | ふたりプラン 800円/月 |
|---|---|---|---|
| 一人ずつ訴える・夜の祠・和解 | ○ | ○ | ○ |
| 女神の鏡（AI） | 1人 月3回 | 本人が月30回 | ふたりとも月30回 |
| 声で訴える | － | 本人 | ふたりとも |
| 学び（アサーション・感情との付き合い方・より良い対人の方法） | 入門のみ | 本人 | ふたりとも |
| 手紙（画面で読める・PDF にもできる） | 読むだけ | 本人が書ける | ふたりとも書ける |
| ローマの朝の祠（共有） | － | ふたりとも | ふたりとも |
| 記録の振り返り（共有） | 直近3件 | ふたりとも | ふたりとも |

- 女神の鏡の回数をプランと追加購入で分けることで、AI の費用を払う人と使う人がそろう
- 「女神の鏡」は、トップページ・掟の画面・鏡の欄の3か所で説明する（初めて見て驚かないように）
- 学びの記事：アサーションってなに？（無料）／怒りの下にある気持ち／Iメッセージ／DESC法／聴くということ／手紙で伝える／いったん休む／関係をこわす4つの言い方／仲直りの言葉／同じ喧嘩をくり返すとき／子どもの前で喧嘩してしまったら／ありがとうを言葉にする
- 手紙は、ブラウザの印刷機能で「PDF に保存」できる

### 演出：祠の版（2種類）
どちらの版も、**画像を少しずつ拡大して近づいていく**演出で始まる。女神の像の足元に着いたら、ふたりの灯りがともり、訴えが始まる。

| 版 | 流れ |
|---|---|
| **夜の祠** | 暗闇に灯りがひとつ → 近づく → 石造りの小さな祠の中、灯りに照らされた女神の像 → 足元に着く |
| **ローマの朝** | パラティーノの丘の上に神殿が見える → 近づく → 柱の間を抜ける → 女神の像の足元に着く |

- 開発は**夜の祠を先に**作り、時間が余ればローマの朝を足す
- 発表では「版を選べる」構想として見せる

### AI 機能（Claude API）

| 項目 | 内容 |
|---|---|
| 使う場面 | 「女神の鏡」のみ（1回の訴えにつき1回） |
| 入力 | 本人の訴えの文章 |
| 出力 | 本人が本当に伝えたいことを、**肯定も否定もせず**短く映し返した文章（例：「あなたは、〇〇のときに△△してほしかった、と伝えたいように聞こえます」） |
| 見る人 | 訴えた本人だけ |
| モデル | Claude Opus 5.5（`claude-opus-5-5`）、effort は `low` |
| 費用 | 喧嘩1回（2人×3往復＝6回）で約20円（2026年11月時点、1ドル150円） |
| 費用の負担 | 開発者（自分）の API キー。管理画面で**月の上限額**（例：1,000円）を設定する。無料プランは月3回まで、1回の祠では10回まで |

**女神の鏡の決まり（システムプロンプトに書く）**
- 肯定しない（「そうですね」「つらかったですね」は言わない）
- 否定しない・裁かない・どちらが悪いかを言わない
- 助言しない・解決策を出さない
- 相手を責める言葉は、本人の「本当は〇〇してほしかった」という形に映し返す
- 短く（2〜3文）

### 安全面
- 訴えの中に**暴力・脅し・強い支配**の気配があるときは、鏡の代わりに相談窓口を案内する
  - 例：DV相談ナビ（#8008）、DV相談＋（0120-279-889）、緊急時は110番
  - ※電話番号は発表・公開前に最新のものを確認する
- 判定はAIに任せる（鏡を作るときに、危険の気配があるかも一緒に返させる）
- 訴えの内容はとても私的なので、ペアの2人以外は見られないようにする

### 画面の流れ

```
[ログイン / 登録]
      ↓
[ホーム] ── 招待コード発行 / 入力でペアになる
      ↓ 「祠へ行こう」
[誘いを待つ] ←→ 相手：[誘いが届いた] → 「応じる」
      ↓
[近づく演出]（夜の祠 / ローマの朝）
      ↓
[掟の確認]「訴えは一人ずつ」→ ふたりとも「従う」
      ↓
[訴えの間] 話す番：入力欄（文字/音声）＋残り時間
           聴く番：「いまは聴く番です」
           共通　：女神の像＋ふたりの灯り
      ↓ 訴え終える
[女神の鏡]（本人だけ）→ 番が交代して [訴えの間] に戻る
      ↓ ふたりとも「祠を出る」
[和解] → 記録を残す / 残さない
      ↓
[記録の一覧]（残した場合）
```

## 5. なぜこのアイディアにしたのか

- 私自身、相手に言いたいことを言えないまま、関係が終わってしまったことが何度もある。だから、これは自分のためのアプリでもある
- このキャンプの期間中にも、身近で関係を解消したカップルとご夫婦がいた
  - ※発表では、誰のことか特定できない言い方にする
- コーチングのブログで、ヴィリプラカの祠のエピソードを読んだ。「一人ずつ訴え、相手は黙って聴く」という2000年前の仕組みは、傾聴と受容というコーチングの基本そのものだった
- 現代の喧嘩はLINEの応酬やスマホ越しになりがちなので、その祠をスマホの中に建て直したいと考えた

「このアプリは、**関係を続けたいふたり**が、**うまくいかないときに、ひとりずつ話せる場所**です。」

## 6. 開発の方針（Claude Code 向け）

### 技術構成
`~/camp/200_python/marche-app` と同じ構成にそろえる。

- Python 3.14 / uv
- Flask, Flask-Login, Flask-SQLAlchemy, Flask-Migrate, Flask-WTF
- 開発は SQLite、本番は MySQL（pymysql）。gunicorn で公開
- `anthropic`（Claude API）。API キーは `.env` に置き、Git に入れない
- テスト：pytest、整形：ruff

### リアルタイムの同期
- 2人の画面の同期（今は誰の番か、相手の灯り、訴えが届いたか）は、**2〜3秒ごとのポーリング（fetch で JSON を取得）**で行う。WebSocket は使わない
- 相手の灯り：ポーリングのたびに `last_seen` を更新し、10秒以内なら「灯りがともっている」とする

### 音声入力
- ブラウザの Web Speech API（`ja-JP`）で文字にする。費用はかからない
- 使えないブラウザでは、文字入力だけにする

### データ設計（案）

| モデル | 主な項目 |
|---|---|
| User | id, 表示名, メール, パスワード（ハッシュ）, pair_id, last_seen |
| Pair | id, 招待コード, 作成日時 |
| Visit（祠への1回の訪問） | id, pair_id, 誘った人, 状態（誘い中/掟確認/訴え中/和解/終了）, 今の話し手, 番の開始時刻, 版（夜/朝）, 記録を残すか（2人分）, 開始・終了日時 |
| Plea（1回の訴え） | id, visit_id, user_id, 順番, 本文, 鏡の文章, 危険フラグ, 作成日時 |

- 「残さない」が選ばれたら、その Visit の Plea はすべて削除する
- 鏡の文章は、書いた本人にしか返さない（API レベルで制御する）

### 顔のない女神（発表で話せるポイント）
- 女神の像には、メトロポリタン美術館の「大理石の女性像」（ローマ帝政期、1〜2世紀、パブリックドメイン）の写真を使う
- この像は頭部が失われている。それを弱みではなく、**「表情で肯定も否定もしない、どちらの味方にもならない女神」**として表現する
- 「顔のない女神の前では、だれかの顔色をうかがう必要はない。自分の言葉と向き合うだけ」
- トップページの「顔のない女神」の段と、由来のページで説明する

### 画像素材
- 女神の像：メトロポリタン美術館 Open Access など、**CC0（パブリックドメイン）**のローマ時代の女性像の写真
- 背景：Wikimedia Commons の PD／CC0、または Unsplash／Pexels のローマ・パラティーノの丘の写真
- ヴィリプラカの像は現存しないため、「ローマ時代の女性像を女神のイメージとして使用」と明記する
- 実在のキャラクターや他社のロゴに似た画像は使わない

### 作る順番
1. ログイン・登録、ペア登録（招待コード）
2. 祠への誘いと応答、掟の確認
3. 訴えの番の切り替え（5分タイマー、入力制限、ポーリング）
4. 女神の鏡（Claude API）と安全面の案内
5. 和解と記録（残す／残さない、一覧）
6. 演出：夜の祠（近づく演出、女神の像、ふたりの灯り）
7. 音声入力
8. （時間があれば）ローマの朝の版

- AIの相槌、AIによる仲裁・助言・判定
- 言い換えた文章を相手に届ける機能
- 通知（プッシュ通知・メール）
- 1人で使うモード、3人以上での利用

### 実装で決めたこと（2026-11-17 一次完成）
- 祠に入ったら、**誘われた側から**訴える（誘った側は先に一歩を踏み出したので）
- 話し手が画面を閉じたまま持ち時間を60秒過ぎたら、番を相手に渡す
- 危険の気配は、AI の判定に加えて言葉による簡単な確認も行う（無料で鏡を使わないときも案内が出る）
- ペアの解消は今回は作らない
